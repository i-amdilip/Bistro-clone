# 🍔 Bistro by Blinkit – Website Clone

A frontend clone of the **Bistro by Blinkit** website, created as my first web development project. The project focuses on recreating the original website's layout, visual design, sections, and footer using HTML and CSS.

## 🚀 About the Project

This project is inspired by the official Bistro by Blinkit website. It is built to practice frontend development concepts and understand how real-world websites are structured and styled.

### ✨ Features

- Clean and visually appealing landing page.
- Navigation bar with an app download button.
- Hero section with promotional content.
- Health & Hygiene section.
- Sustainability section.
- Speed and delivery section.
- Social media links and icons.
- Google Play Store and Apple App Store links.
- Custom footer with useful links.

## 🛠️ Technologies Used

- **HTML5** – Website structure and content.
- **CSS3** – Styling, layouts, colors, and positioning.
- **Google Fonts** – Typography.
- **Local Assets** – Images and social media icons.

## 💻 Getting Started

Follow these steps to run the project locally:

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project folder:

   ```bash
   cd Bistro-Clone
   ```

3. Open `index.html` in your browser.

You can also use the **Live Server** extension in VS Code.
